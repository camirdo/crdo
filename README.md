# Camila Ruiz Diaz Odena — Sound · Film · Social Research

First static version of the personal website, built from the existing Cargo content and the poster archive supplied for the migration.

## Structure
- `index.html` — Home
- `sound-in-film.html` — film sound work and posters; posters link to the existing trailers/IMDb pages
- `research.html` — research landing page
- `sound-identities.html` — Sound Identities #01 with the supplied San Telmo recording
- `research-projects.html` — research projects and reading material
- `about.html`
- `contact.html`
- `styles.css` — global layout and responsive styles
- `script.js` — clock
- `assets/posters/` — supplied poster images
- `assets/audio/` — supplied San Telmo WAV
- `assets/ciudades-que-suenan.pdf` — supplied PDF

## Publishing
This is a static site, so it can be published on GitHub Pages, Netlify, Cloudflare Pages, or another static host without a site builder.
